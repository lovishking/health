## 2. Project objective

Build a real-time patient deterioration early-warning and clinical decision-support prototype.

The application must receive timestamped physiological measurements, store them, process them, assess potential risk, explain its output, and display the results on a live dashboard.

The initial data source will be historical ICU data replayed at configurable intervals. Real wearable integration is future scope.

The system must never claim that it can determine with certainty whether someone will live or die. It is a research prototype that supports clinical review; it does not replace a qualified healthcare professional.

## 14. Phase 9: Hybrid fusion, safety override and SHAP

Implement the hybrid decision fusion:

P_H(c) = alpha * P_S(c) + (1 - alpha) * P_T(c)

where:
- P_S is the XGBoost class probability.
- P_T is the LSTM class probability.
- alpha is configured and selected using suitable validation results.

Start with the report's proposed alpha of 0.5, but do not claim that this is optimal without evaluation.

Integrate the safety-rule override after fusion. Record the model output, the final output, the rule-trigger reason and the model version.

Implement TreeSHAP for the XGBoost model. Store the feature contributions and generate a concise explanation that accurately reflects the model output. Do not state that a feature caused a patient's condition.
